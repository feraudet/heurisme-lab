# antenne-polarisation

This bench goes with the deck https://heurisme.fr/en/blog/antenne-polarisation/ : how much signal an ADS-B receiver (1090 MHz) loses when its antenna is mounted horizontally while aircraft transmit with a vertical antenna. Two half-wave dipoles are simulated with NEC2 (nec2c); one of them is rotated from 0 to 90 degrees, then a tilted wire is added beside the link, then both ends become turnstiles (circular polarization).

File names are in French because the original article is. Useful names: `rejouer.sh` = replay script, `modele.py` = model (writes the NEC2 input decks), `analyse.py` = analysis, `nec/` = NEC2 input decks, `raw/` = nec2c outputs, `sorties/` = outputs. Steps: `rotation`, `reflet` = reflection, `portee` = range, `circulaire` = circular. The outputs themselves are in English.

## How to replay

- Docker. nec2c runs in `debian:bookworm` pinned by digest (`sha256:2c037a04925515fdd6ea85ea14a682d0e79931f5e9f5d07b6dbfc6ba12f9e858`), with the package `nec2c 1.3-4` installed from `snapshot.debian.org` at `20261010T000000Z`.
- Python 3.9 or later on the host, standard library only.
- Network access for `apt-get` inside the container. No third-party data is downloaded.

Single command:

```bash
bash rejouer.sh
```

It rewrites `nec/` (`modele.py`), runs nec2c on every deck into `raw/`, then rewrites `sorties/01-rotation.txt` to `sorties/04-circulaire.txt`. Compare with the files provided: they come out byte for byte the same. `raw/` is not stored here: it is regenerated by the script, and the nec2c listings carry run times that change from run to run.

## Model

- Frequency 1090 MHz, wavelength 27.50 cm. Dipoles 13.0 cm long, wire 1 mm in diameter, 21 segments; the feed point (the "port") is segment 11.
- The two antennas face each other along the y axis, 2.75 m apart (10 wavelengths), in free space.
- `01-rotation`: transmit dipole vertical; receive dipole rotated about the y axis (the line of sight) by 0, 15, 30, 45, 60, 75, 80, 85, 89 and 90 degrees. A last structure gives the far field of a lone vertical dipole toward the receiver (gain, E(theta), E(phi)).
- `02-reflet`: same link at 0 and 90 degrees, plus a 1 m wire tilted 45 degrees in the plane perpendicular to the link, halfway along it (y = 1.375 m) and centred 50 cm to the side (x = 0.5 m).
- `03-circulaire`: a turnstile at each end (one vertical and one horizontal dipole, crossed). Two crossed wires cannot share a point in NEC2, so the horizontal dipole sits 4 mm behind the vertical one along the link; the 90 degree feed phase includes the extra path (k x 4 mm). Four structures excite each turnstile alone with +90 and -90 degrees and print the polarization sense nec2c computes toward the other end (RIGHT or LEFT).

## Method: coupling between ports

Each NEC2 structure excites ONE port with a 1 V source. The other ports are ordinary wire segments, so they are short circuits. The current read at every port gives one column of the port admittance matrix Y. `analyse.py` inverts Y into the impedance matrix Z, then computes the coupling as the power delivered to a conjugate-matched load on the receive port divided by the power fed to the transmit port:

    G = |Z_rt|^2 / (4 Re(Z_tt) Re(Z_rr))

This is the weak-coupling form (the receive load does not change the transmit current); at 10 wavelengths the coupling is below -37 dB, so the approximation holds. Check: at 0 degree the bench gives -37.71 dB, and Friis with the dipole gain computed by nec2c (2.14 dBi) gives -37.70 dB (`sorties/01-rotation.txt`, line 19).

For the turnstiles, transmit currents are (1, w) on the vertical and horizontal dipoles, with w = +j or -j times the 4 mm phase. On receive, the two open-circuit voltages are combined by an ideal 90 degree hybrid into one matched load: P = |V_v + c V_h|^2 / (16 R). The weights c that match a given sense come from the nec2c sense check, by reciprocity. The two receive dipoles do not couple (|Z34| below 1e-14 ohm, line 8 of `sorties/04-circulaire.txt`).

At exactly 90 degrees, the two dipoles are crossed and the coupling is nil by symmetry. nec2c returns a current of the order of 1e-20 A, a rounding residue; the output prints it as `< -200 dB`.

The 10 dB case in `sorties/03-portee.txt` is not computed by the bench: it is the average cross-polarization discrimination in open areas measured at 900 MHz, quoted from Recommendation ITU-R P.1406-2, section 5.1.1 (https://www.itu.int/rec/R-REC-P.1406/en). The 200 km range is an example value, not a measurement.
